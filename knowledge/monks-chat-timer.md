# Monk's Chat Timer v14.01 — Temporizador en Chat

## API

```js
// Sin global; clase MonksChatTimer
```

## Hooks

- `chatCommandsReady`, `chatMessage`, `renderChatMessageHTML`, `setupTileActions`

## Uso

- Crea una tarjeta de chat con temporizador (cuenta arriba/abajo). Comando `/timer <seg> flavor:String followup:String` (negativo cuenta hacia abajo). Popout de la tarjeta.

## Dependencias

- `_chatcommands` (Chat Commander) — **requerido**.
