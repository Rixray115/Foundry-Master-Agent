# Monk's Hotbar Expansion v14.01 — Hotbar Expandido

## API

```js
// Sin global de API; clase MonksHotbarExpansion
```

## Hooks

- `hotbarDrop`, `init`

## Uso

- Expande todas las filas del hotbar a la vez (sin paginado); selección directa de fila por número, borrar una fila completa de macros.

## Dependencias

- Ninguna (standalone)
