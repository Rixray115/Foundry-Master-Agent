# Tidy 5e Sheets v13.5.0 — Hojas dnd5e V14

## API Global

```js
game.tidy5e          // o Tidy5eSheetsApi2 (v2 API)
```

## Hooks

- `tidy5e-sheet.ready`
- `tidy5e-sheet.renderCharacterSheet` / `renderNPCSheet`
- `tidy5e-sheet.getCharacterSheetCharacterSection` (extender secciones)

## Uso

- Reemplaza las hojas por defecto de dnd5e (character/NPC) con layout configurable.
- Permite favoritos, secciones personalizadas y botones de macro en la hoja.

## Dependencias

- dnd5e system (V14)
