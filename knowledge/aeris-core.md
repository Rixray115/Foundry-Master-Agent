# Aeris Core v13.0.23 — Framework Cinemático

## API Global

```js
aerisCore
lenisVersion
```

## Hooks

- `aeris-core.import-css`
- `aeris-core.registerChatComponents`
- `renderChatMessageHTML`

## Uso

- Framework de UI/chat animada (scroll suave vía lenis, componentes de chat cinemáticos).
- Base de los módulos cinemáticos Aeris (aeris-animations, aeris-cinematic-bars, aeris-cinematic-view, aeris-smooth-camera).

## Dependencias

- Ninguna (standalone)
