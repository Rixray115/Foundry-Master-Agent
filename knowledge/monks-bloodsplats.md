# Monk's Bloodsplats v14.01 — Charcos de Sangre

## API

```js
// Sin global de API; clase MonksBloodsplats
```

## Hooks

- `createCombatant`, `deleteCombat`, `destroyToken`
- `updateToken`, `refreshToken`, `lightingRefresh`, `sightRefresh`

## Uso

- Muestra criaturas muertas como un charco de sangre en lugar del token (mantiene el campo de batalla limpio).
- Configurable: color, transparencia, tamaño; el GM siempre ve el token, los jugadores ven el charco por defecto.

## Dependencias

- Ninguna (standalone)
