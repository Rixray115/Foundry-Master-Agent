# Aeris Animations v13.0.9 — Animaciones Cinemáticas

## API Global

```js
aerisAnimations
```

## Hooks

- `ready`
- `socketlib.ready`

## Uso

- Capa de animaciones para el framework cinemático Aeris (animaciones scriptadas de token/scene).
- Parte del ecosistema Aeris (aeris-core, aeris-cinematic-bars, aeris-cinematic-view, aeris-smooth-camera).

## Dependencias

- aeris-core (framework base)
