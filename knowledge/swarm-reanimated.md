# Swarm Reanimated v14.0.2 — Enjambres

## API Global

```js
SWARMS
```

## Funciones Principales

```js
// Convertir un token en enjambre animado
await SWARMS.createSwarm(token);

// Remover
await SWARMS.removeSwarm(token);
```

## Hooks

- `swarm-reanimated.ready`

## Uso

- Sección "Swarm" en config de token: vuelve al token un enjambre de partículas animado (flavor de encuentro).

## Dependencias

- Ninguna (standalone)
