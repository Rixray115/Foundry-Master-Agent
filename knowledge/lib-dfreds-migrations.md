# Lib: DFreds Migrations v1.0.3 — Migraciones

## API Global

```js
migrations
```

## Hooks

- `migrations.init` / `migrations.setup` / `migrations.ready`

## Uso

- Runner de migraciones versionadas tipado (MigrationsImpl2) para datos/mundos de módulos DFreds.
- Usado internamente por Convenient Effects, etc.
