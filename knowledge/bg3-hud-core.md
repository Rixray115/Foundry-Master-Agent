# BG3 Inspired HUD - Core v0.4.3 — HUD estilo BG3

## API

```js
// Sin global; framework de componentes HUD
```

## Hooks

- `bg3HudReady`
- `bg3HudRegistrationComplete`
- `createToken`
- `getSceneControlButtons`

## Uso

- Framework base para un HUD inspirado en Baldur's Gate 3 (componentes, tooltips, contenedores, persistencia, sockets).
- REQUIERE un adapter de sistema (bg3-hud-dnd5e para dnd5e) para funcionar.

## Dependencias

- bg3-hud-dnd5e (adapter del sistema, requerido)
