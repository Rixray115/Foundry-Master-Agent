# Monk's Modules Suite — Utilidades para Foundry V14

## Resumen

Colección de módulos de "TheRipper93" que añaden utilidades QoL a Foundry.
Todos los módulos están actualizados para **Foundry V14**.

## Módulos

### Monk's Active Tile Triggers v14.01
Dispara eventos al pisar/entrar/salir de tiles.

```js
// Configuración via UI del tile
// Triggers disponibles:
// - Token enters tile
// - Token exits tile
// - Token moves within tile
// - Click on tile

// Acciones disponibles:
// - Execute macro
// - Move token
// - Toggle tile
// - Play sound
// - Change scene
```

### Monk's Bloodsplats v14.01
Sangre visual en tokens según HP.
- Automático: más daño = más sangre
- Configurable: tamaño, opacidad, estilo

### Monk's Combat Details v14.02
Info detallada de combate en chat cards.
- Damage breakdown
- Resistance/vulnerability info
- Critical hit details

### Monk's Combat Marker v12.01
Marca turnos y condiciones en el tracker de combate.

### Monk's Common Display v14.01
Muestra elementos comunes en todas las pantallas (ideal para mesa presencial).

### Monk's Hotbar Expansion v14.01
Hotbar expandido con más slots y mejor organización.

### Monk's Little Details v14.01
QoL variado:
- Auto-target tokens
- Token resize
- Better drag-drop
- HUD improvements

### Monk's Player Settings v14.01
GM edita/sincroniza settings de jugadores.

### Monk's Scene Navigation v14.02
Navegación de escenas y permisos por escena.

### Monk's Sound Enhancements v14.01
Sonidos ambientales por escena:
- Background music per scene
- Ambient sounds
- Sound transitions

### Monk's TokenBar v14.01
Barra lateral de tokens con funciones de guardado rápido, ST/contested/XP.

### Monk's Wall Enhancement v14.01
Walls avanzados:
- One-way walls
- Wall height
- Better wall rendering

### Monk's Chat Timer v14.01
Timer en chat via `/timer` (requiere Chat Commander).

## TheRipper93's Module Hub v5.0.7
Hub que gestiona todos los módulos de TheRipper93:
- Configuración centralizada
- Licencias
- Actualizaciones

## Dependencias
- Requiere: socketlib (para features multiplayer)
- Requiere: libWrapper (para patches)
