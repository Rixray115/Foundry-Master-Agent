# Monk's Sound Enhancements v14.01 — Mejoras de Sonido

## API

```js
MonksSoundEnhancements   // global (window.MonksSoundEnhancements)
// Clase MonksSoundEnhancements
```

## Hooks

- `renderPlaylistSoundConfig`, `renderJournalPageSheet`, `updateCombat`, `hotbarDrop`
- `globalSoundEffectVolumeChanged`

## Uso

- Mejoras de playlist/sons: pestaña de sons en config, play privado, drag&drop de sons, checkboxes de import por archivo, ocultar nombres de son/playlist; SFX de actor (botón en Token HUD / ficha) y de ítem (al usarse); slider global de volumen de SFX (lo usan otros módulos como Active Tiles / Enhanced Journal).

## Dependencias

- Ninguna (standalone)
