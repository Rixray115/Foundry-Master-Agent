# Lib: DFreds UI Extender v2.3.0 — Extender la UI

## API Global

```js
uiExtender
```

## Hooks

- `uiExtender.init` / `uiExtender.setup`
- `render${type}HUD` — inyectar controles HUD
- `renderSidebar` — añadir directorios
- `getSceneControlButtons` — añadir controles de escena

## Uso

- Añade directorios a la sidebar, controles HUD a tokens/teselas/drawings, y controles de escena a cualquier capa.
- Librería tipada (Typescript); usada por los módulos de DFreds (p. ej. UI del catálogo de Convenient Effects).

## Dependencias

- libWrapper
