# Monk's Wall Enhancement v14.01 — Mejoras de Muros

## API

```js
// Sin global; clase MonksWallEnhancement
```

## Hooks

- `renderWallConfig`, `renderSceneConfig`, `renderSceneControls`
- `getSceneControlButtons`, `getSceneContextOptions`, `preUpdateScene`

## Uso

- Mejoras de muros: arrastrar puntos unidos, split por doble-click, join points (Shift), condensar tipos, freehand draw, convertir drawing a muro, toggle secret door (Ctrl+RC), "Wall Off Scene", "Close All Doors", iconos claros, hotkeys de tipo de muro.

## Dependencias

- Ninguna (standalone)
